# 原料代表种植产区：数据与出处说明

核查日期：2026-10-02。共 46 个代表点、9 类原料、24 个国家；包括先前 38 点及本轮 8 个跨洲补充点。中国合计 7 点，保留原有云南普洱咖啡点。

酿酒原料代表种植产区，并非全球全部产区或任一酒款的采购来源。

坐标是产区内城市附近的区域示意点，取一位小数；不是田块、农场、厂址或产区边界。 坐标为本项目整理的示意中心，并通过仓库自带 Natural Earth 1:50m 国界多边形核对；此检查只能发现国别与海陆错误，不能证明某块土地正在种植。每个点的农作物依据另见下表。

大麦、小麦、燕麦、黑麦先是农作物；是否制麦或用于酿酒取决于品种、质量与加工。柑橘、芫荽、咖啡、可可是可选辅料。 水和酵母没有被标为种植产区。

气候文字是作物生长的一般要求或区域农技资料；不是当天天气的适种评分，也不能替代当地农艺判断。 同一作物的品种、播期、海拔、土壤与灌溉会改变实际表现；其中部分气候来源是一般农技指南，不是每个示意点的气候观测。季节信息区分农事资料中的典型窗口和有日期的现场采收观察，不接入实时天气；`regional_crop_observation` 不代表已取得完整作期或统一最佳月份。

中文短摘要与近似坐标由本项目整理，原网站和研究报告的内容权利归相应机构。本文件保留链接以便回查，不声明这些链接目标适用本项目的软件许可证，也未复制原报告、照片或农田边界。较早报告仅用于确认长期种植区域和作物知识，未将旧统计量当作当前产量或排名。

## 生长与采收季节

季节文字是典型生长或采收窗口，月份均为当地公历；品种、播期、海拔及雨季变化会影响实际日期，不是实时天气或逐农场预测。

国别作期只表示较大范围的常见窗口，不是示意点逐农场观测。某一年的播种或收获报道只用于说明季节，未当作每年固定日期；籽粒作物和干草用途、柑橘早中晚熟品种分别看待。

| 区域 | 季节摘要 | 季节出处 |
| --- | --- | --- |
| 萨斯喀彻温大麦区 | 春播、夏季抽穗灌浆，夏末至秋季收获；春雨和秋雨会使播收时间提前或推迟。 | [1][CAL1]、[2][CAL2] |
| 西澳大麦种植带 | 南半球秋季4—5月是重要播种窗口，冬春生长；播期需按品种及降雨调整，兼顾霜冻和后期干热。 | [1][CAL3] |
| 苏格兰大麦区 | 春大麦通常春季播种、春夏生长；谷物收获多在8—9月，湿冷春季会推迟播种。 | [1][CAL4]、[2][CAL5] |

| 扎泰茨／萨兹啤酒花区 | 春夏生长、夏末至初秋采收；捷克不同啤酒花品种的成熟窗口可从8月延续到9月。 | [1][CAL8] |

| 新南威尔士南部小麦区 | 南半球4—5月秋播、冬春生长，春季开花，11—12月前后收获；快熟与慢熟品种的播期不同。 | [1][CAL13]、[2][CAL14]、[3][CAL15] |
| 萨斯喀彻温燕麦区 | 春季播种、夏季生长，夏末至秋季成熟采收；实际进度随当年雨水和品种变化。 | [1][CAL16]、[2][CAL2] |
| 苏格兰燕麦区 | 当地燕麦多为春播，春夏生长，谷物收获通常在8—9月；成熟和收获受降雨影响。 | [1][CAL17]、[2][CAL5] |
| 西澳燕麦种植带 | 南半球秋播、冬春生长，4—5月播期需结合品种选择；籽粒用和干草用燕麦的收获阶段不同。 | [1][CAL18]、[2][CAL19] |
| 勃兰登堡黑麦区 | 冬黑麦秋播并越冬，次年春季继续生长；当地试验的播种窗口在9月下旬至10月上旬。 | [1][CAL20] |
| 明尼苏达黑麦种植区 | 秋播越冬，播期多在9月，州南部可延至10月；春季恢复生长，籽粒通常夏季收获。 | [1][CAL21]、[2][CAL22] |

| 科塔—拉姆甘杰曼迪芫荽区 | 凉季作物，通常10—11月播种、冬季生长；新季芫荽籽在2—3月集中上市。 | [1][CAL26] |
| 萨斯喀彻温芫荽区 | 4月下旬至5月中旬春播、夏季生长；大粒型约需100—110天生长季，小粒型更长，种子成熟后采收。 | [1][CAL27] |
| 米纳斯吉拉斯咖啡区 | 南半球秋冬约5月起进入采收，常持续至7—8月；按咖啡果成熟度分批采摘。 | [1][CAL28] |

| 得乐／邦美蜀咖啡区 | 邦美蜀咖啡通常10—12月分批采熟果；干季仍需供水，宜按当地雨旱季理解生长周期。 | [1][CAL30] |
| 云南普洱咖啡区 | 秋末冬初开始鲜果采摘；各批次按果实成熟度采收，海拔与降雨会影响具体时间。 | [1][CAL31] |
| 塞夫维维奥索可可区 | 按加纳国别作期，主采收约9月至翌年3月，中季约5—8月；实际随雨旱季及成熟批次变化。 | [1][CAL32] |
| 苏布雷可可区 | 按科特迪瓦国别作期，主采收约10月至翌年3月，中季约5—8月；实际随雨季和成熟批次变化。 | [1][CAL32] |
| 洛斯里奥斯可可区 | 按厄瓜多尔国别作期，主采收约3—6月，中季约10月至翌年2月；赤道附近宜按雨旱季与成熟批次理解。 | [1][CAL32] |
